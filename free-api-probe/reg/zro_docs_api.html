API reference

Endpoints, authentication, streaming, tool calling, reasoning, caching, and regions.

The API exposes three surfaces from the same host, authenticated with the same per-user API keys: Chat Completions, the Responses API, and the Messages API.

APIBase URLEndpoint
Chat Completionshttps://zro.moonmath.ai/v1POST /chat/completions
Responseshttps://zro.moonmath.ai/v1POST /responses
Messageshttps://zro.moonmath.aiPOST /v1/messages

Authentication

Create an API key from the API keys page and send it as a bearer token:

Keys are scoped to an invoice-able account, carry optional spend limits and expiry, and select which regions may process their requests. They can be created, revoked, and inspected at any time from the API keys page. See Key controls and Regions.

Streaming

Set stream: true to receive server-sent events. All models stream, and usage is included in the final chunk.

Messages API

Claude Code and other Messages clients point at the endpoint root (not /v1).

Tool calling

The standard tools / tool_choice interface and the full tool-call loop are supported. This is what lets coding agents run shell commands, edit files, and call MCP tools.

Reasoning

Reasoning models accept an effort control, shaped per API:

APIField
Chat Completionsreasoning_effort, reasoning, or thinking
Responsesreasoning
Messagesthinking, or output_config.effort

On Chat Completions, when more than one is sent, precedence is reasoning_effort > reasoning > thinking.

The reasoning object accepts {"effort": "<level>"} or the boolean toggle {"enabled": true|false}. The supported levels differ per model. See the reasoning chips on the Models page. Unrecognized reasoning fields are ignored rather than rejected.

Errors

Errors follow the standard error shape ({ "error": { "message", "type", ... } }).

StatusMeaning
400Malformed request or unsupported parameter value.
401Missing, invalid, revoked, or expired API key.
403Key is not permitted to use the requested model.
402Spend quota or plan budget exhausted.
404Unknown model ID.
429Rate limit exceeded. Retry with backoff.
5xxUpstream/model error. Retry with backoff; if it persists, contact support.

Compatibility notes

  • Standard request fields (temperature, top_p, max_tokens, frequency_penalty, presence_penalty, stop, seed) are accepted.
  • Unsupported provider parameters are dropped instead of erroring. Clients built for other providers keep working.
  • Both the bare model ID and its zro/ alias are accepted on every endpoint.

CLI

Install the zro CLI, authenticate once, and launch any supported coding agent against the API.

Integrations

Point Claude Code, Codex, OpenCode, Cursor, Cline, and other coding agents at the API.
