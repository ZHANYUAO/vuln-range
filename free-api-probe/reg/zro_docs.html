Introduction

Models, pricing, the API, and setup for every supported coding agent.

Zro is a fast, private, multi-region inference service for open models. It exposes the Completions / Responses API and the Messages API, with zero request retention and no training on customer requests.

This is the working reference. Start with the quickstart to make your first request, then dig into the models, the API, or a specific integration.
