Under the hood

Built for agents that run all day.

Follow one request through xKiro. Failover, streaming, fair billing, budgets and logs are part of the path — not add-ons.

  1. 01

    Routed — with a fallback

    When a model has more than one route, a failing upstream is retried on the next route automatically — no retry code on your side.

    POST/v1/chat/completionsopenai/gpt-6.1-sol
    route 1503 upstream busy
    route 2200 OK · streaming
    ↳ same model, next route
  2. 02

    Streamed token by token

    Answers arrive as they are generated, in the OpenAI or Anthropic streaming format your client already parses.

    data: {"choices":[{"delta":{"content":"Cache"}}]}
    data: {"choices":[{"delta":{"content":" hits"}}]}
    data: {"choices":[{"delta":{"content":" skip"}}]}
    data: {"choices":[{"delta":{},"finish_reason":"stop"}]}
    data: [DONE]
    Cancel at any point — you pay only for the tokens generated. · Example
  3. 03

    Billed fairly

    Metered at catalog rates. The rules are simple and written down:

    • ✓Requests that fail with a 5xx error are never billed
    • ✓Retrying an identical blocking request replays the first result — no double charge
    • ✓Cancel a stream and pay only for the tokens generated
  4. 04

    Spent against budgets you can see

    Plans spend from a 5-hour and a 7-day allowance at catalog rates — watch both fill up in real time.

FAQ

Questions, answered

How plans, free models and billing actually work.

Still have a question? Contact us →
Is there really a free tier?

Yes. 45 models are free to call on every account, within a daily allowance of 500K tokens — 1M after you verify on Telegram. No credit card required.

Which SDKs and tools work with xKiro?

The OpenAI and Anthropic SDKs, and anything built on them. Use https://api.xkiro.com/v1 as the base URL for OpenAI clients and https://api.xkiro.com for Anthropic clients such as Claude Code, then pass any model ID from the catalog. Claude models are the exception: they accept requests only from Anthropic’s official tools, such as Claude Code.

How do plan budgets work?

Each paid plan includes a spending allowance over a 5-hour and a 7-day window, measured at catalog rates. Usage inside both windows is covered by the plan; unused budget does not carry over to the next window.

What is the difference between a plan and pay-as-you-go?

A plan is a fixed monthly price with usage budgets. Pay-as-you-go draws from a prepaid wallet balance, charged per request at catalog rates — used when you have no plan, and for the few models billed outside plan budgets.

Am I charged for failed requests?

No. Requests that fail with a 5xx error or never reach a provider are not charged. If you cancel a stream, you pay only for the tokens generated before you stopped.

What happens when a model is down?

When a model has more than one route, xKiro retries on the next route automatically, so a single upstream outage does not have to fail your request.

Can I cancel or upgrade my plan?

Yes. Cancel auto-renewal at any time from Billing and keep access until the end of the period. You can upgrade from the pricing page in your dashboard.

Can I use xKiro for commercial projects?

Yes. All plans, including the free tier, allow commercial use. Usage is also subject to each model provider's terms.
