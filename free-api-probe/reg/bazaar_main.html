2026-10-08
AI Agent 可以自己領 API Key 了，並支援 OKX x402 付款
BazaarLink 重新開放 AI Agent 自助註冊，並新增以 x402 付款的註冊與儲值方式。 **1. Agent 自己領 Key** Agent 呼叫一次 `POST https://bazaarlink.ai/api/v1/agents/register`（帶 `name`）就能取得自己的 API Key，不需要註冊表單、不需要人工審核。回應包含 `api_key`（只顯示一次）與 7 天內可供人類認領帳號的 `claim_token`。 這樣註冊的是未付費帳戶：可使用免費模型（`auto:free`），受一般速率與每日上限限制；同一個 IP 或雲端供應商的註冊次數有上限。 **2. 用 x402 付款（OKX）** 需要付費模型的 Agent，可以在註冊時直接付款：`POST https://bazaarlink.ai/api/v1/agents/register/x402`。付款使用 X Layer 上的 USD₮0，透過 OKX 的 x402 facilitator 結算，付款方不需要 OKB 當 gas，可用 OKX Wallet 或任何 EVM 錢包簽名。之後補額度呼叫 `POST https://bazaarlink.ai/api/x402/topup`。 平台會收取儲值手續費，入帳額度會低於付款金額；回應會分開列出 `paidUsd`、`creditedUsd`、`serviceFeeUsd`。 **3. 注意** 這些帳號端點在 `bazaarlink.ai`；聊天與模型呼叫仍使用 `https://api.bazaarlink.ai/v1`。 文件：[x402 整合](/docs/integrations/x402)・[方案介紹](/solutions/x402-agent-payments)・[Agent 專區](/agents)
