Questions before you integrate

What BeatAPI is, how agents connect, what they can call, and how billing works.

Get your API key

Create a key, send your agent one setup line, then let it search, inspect and run.

Create API key

BeatAPI is the capability layer for AI agents. One API key gives Claude Code, Codex, Cursor, Muse or your own app access to 70+ AI models, 1,000+ social data APIs and web tools for search, page reading and research. Your agent finds the right capability, checks its inputs and price, then runs it.

A model router forwards chat requests to LLMs. BeatAPI also covers social data, web tools and image, video and workflow tasks, and it is built for agents to use on their own: search the catalog, inspect a capability's input schema and price, then run it. The agent reads the contract before it spends anything.

Claude Code, Codex, Cursor, OpenCode, Muse and any client that supports MCP or can make HTTP requests. Each agent has a setup guide on the Integrations page, and apps can call the same API directly.

Send your agent one line: set up https://beatapi.io/SKILL.md. It reads the guide and asks for your key. For MCP hosts, add the server https://beatapi.io/mcp and put your key in the host's secret settings. Never paste a key into chat.

Public data from TikTok, Instagram, YouTube, X, Reddit, LinkedIn, Threads, Xiaohongshu and Douyin: posts, profiles, comments, search results and trends. Web tools add search, page reading, site maps and multi-step research. Results come back as structured JSON your agent can rank, compare and cite.

No. One BeatAPI key and one USD balance cover models, social data and web tools. There are no per-vendor accounts, separate bills or provider keys to rotate.

Calls spend a prepaid USD balance. Every capability publishes its price before you run it, and every response reports what the call cost. Model prices are listed next to the official provider rate on the pricing page.

Data and web calls that fail on our side are not charged. For image, video and workflow tasks, BeatAPI reserves the price when the task is accepted and refunds eligible failures to your balance. Every error also says whether a retry can succeed, so agents don't loop.

Yes. A finished image or video task returns a hosted file URL on the task record, so your agent can hand over a link without you setting up storage.
